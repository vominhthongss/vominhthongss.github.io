# vominhthongss.github.io

Static directory for five projects, with Tailwind CSS v4 and a shared multilingual navigation script.

## Local development

```sh
npm install
npm run build
python3 -m http.server 8000
```

Open http://localhost:8000. Rebuild CSS after changing HTML classes. Pull requests build CSS; only the main branch can deploy. All five projects have local landing pages, with the four external web apps retaining links to their original websites.

The Lofi Garden policy and app-ads.txt URLs remain unchanged. Supported languages: en, vi, ja, ko, zh_CN, zh_TW, fr, de, th, km.
